# Ordinary developer traffic. Replayed against settings.template.json, NOTHING here may be DENIED.
#
# This is the over-reach half of the template's acceptance test. It cannot, on its own, tell a good
# floor from an empty one -- a floor that denies nothing passes it perfectly. That is why it is
# paired with the must-deny set in test_template_floor.py; neither half means much without the
# other. Replay the two together or not at all.
#
# Most entries land UNMATCHED rather than ALLOW, because the template ships an empty `allow` on
# purpose. UNMATCHED is not a regression: it means the recipient will be prompted, which is the
# correct default for traffic nobody has approved yet. Only DENY is a regression.
#
# Bring your own corpus too. An accumulated settings.local.json is the best one available -- every
# literal in it is a command that actually ran and was actually approved.
#
#     python replay_permissions.py --candidate settings.template.json --corpus corpus/approved.example.txt

# -- version control -----------------------------------------------------------------------------

PowerShell(git status)
# The SAFE force-push form. It must survive the floor; `git push --force*` would swallow it.
Bash(git push --force-with-lease origin feature/parser)
